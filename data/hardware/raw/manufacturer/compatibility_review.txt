공식 제조사 자료를 직접 확인했어. **CPU 지원 여부와 최소 BIOS는 확인했고, RAM은 정확한 품번까지 일치하는 항목과 추가 확인이 필요한 항목을 구분했어.** 아래는 **2026년 11월 11일 조회 기준**이야.

먼저 CPU 지원표에서 앞서 선정한 CPU 4종을 추리면 다음과 같아.

| CPU | ASRock A620AM-HVS | ASUS TUF GAMING B850-PLUS WIFI | MSI MAG B650 TOMAHAWK WIFI |
|---|---:|---:|---:|
| Ryzen 5 8600G | **3.20** | **ALL** | **7D75v1E** |
| Ryzen 5 7600 | **3.20** | **ALL** | **7D75v10** |
| Ryzen 9 7900 | **3.20** | **ALL** | **7D75v10** |
| Ryzen 5 9600X | **3.20** | **ALL** | **7D75v1H** |

원본: [ASRock CPU 지원표 — Support → CPU Support List](https://www.asrock.com/mb/AMD/A620AM-HVS/index.asp#Support), [ASUS CPU 지원표](https://www.asus.com/motherboards-components/motherboards/tuf-gaming/tuf-gaming-b850-plus-wifi/helpdesk_cpu?model2Name=TUF-GAMING-B850-PLUS-WIFI), [MSI CPU 지원표](https://www.msi.com/Motherboard/MAG-B650-TOMAHAWK-WIFI/support#cpu)

읽을 때는 다음을 구분하면 돼.

- **ALL**: 해당 CPU가 모든 BIOS에서 지원된다는 공식 표기야. ‘정보 없음’이 아니야.
- **ASRock**: `Validated BIOS`와 `Bootable since BIOS`를 구분해서 제공해. 위 CPU 4개는 두 값 모두 **3.20**이야.
- **MSI**: 표의 `Result`에 표시되는 BIOS 파일명에서 `.zip`을 제외한 버전이야.
- 실제 구매할 메인보드에 설치된 BIOS는 따로 확인해야 해.

|---|---|---|---|---|---|

**여기서 ASRock RAM 표의 BIOS 3.50을 곧바로 ‘최소 BIOS’로 저장하면 안 돼.** QVL의 BIOS 항목은 검증에 사용된 BIOS 정보로 보존하고, 최소 버전이라고 명시된 근거가 있을 때만 `min_bios_version`에 넣는 게 맞아. ASUS와 MSI의 위 RAM 행에는 BIOS 버전이 표시되지 않았어.

기존 RAM 후보 중 아직 구분해서 다뤄야 하는 것도 있어.

| 기존 후보 | 확인 결과 | 처리 방향 |

64GB 제품의 원본: [G.SKILL F5-6000J3040G32GX2-FX5 공식 QVL](https://www.gskill.com/qvl/165/396/1691400033/F5-6000J3040G32GX2-FX5-QVL). 여기서는 메인보드 제조사가 아닌 **G.SKILL이 검증 주체**라는 점을 함께 남겨야 해.

`part_compatibility`에는 아래처럼 저장하면 돼. 표에서는 읽기 쉽게 부품명을 썼지만, 실제 `part_a_id`와 `part_b_id`에는 해당 `parts`의 ID가 들어가.

| 예시 행 | part_a_id → part_b_id | check_type | support_status | min_bios_version | conditions에 보존할 내용 |
|---|---|---|---|---|---|
| C01 | MSI B650 → 8600G | CPU_SUPPORT | CONDITIONAL | **7D75v1E** | CPU 지원표의 BIOS 조건 |
| C02 | MSI B650 → 9600X | CPU_SUPPORT | CONDITIONAL | **7D75v1H** | CPU 지원표의 BIOS 조건 |
| C03 | ASRock A620AM-HVS → 8600G | CPU_SUPPORT | CONDITIONAL | **3.20** | 검증 BIOS 3.20 / 부팅 가능 BIOS 3.20 |
| C04 | ASUS B850 → 7900 | CPU_SUPPORT | SUPPORTED | 비움 | BIOS 적용 범위 **ALL** |
| C05 | ASUS B850 → Flare X5 32GB | MEMORY_QVL | CONDITIONAL | 비움 | CPU 계열 7000·9000, DIMM 1·2개, 6000 MT/s, EXPO, 1.35V |
| C06 | MSI B650 → Flare X5 32GB | MEMORY_QVL | CONDITIONAL | 비움 | CPU 계열 **9000**, DIMM 1·2개, SPD 4800 / 검증 6000 MT/s, 1.35V |
| C07 | ASRock A620AM-HVS → 삼성 **M323R2GA3DB0-CWMOD** | MEMORY_QVL | CONDITIONAL | 비움 | CPU 계열 **8000**, DIMM 2개, 5600 MT/s, **검증 BIOS 3.50** |

C07은 정확한 삼성 품번으로 `parts`를 등록하거나 기존 상품과의 동일성을 확인한 뒤 연결하는 예시야.

각 행에는 다음 출처 정보도 붙여야 해.

| 저장 항목 | 저장 내용 |
|---|---|
| `source_url` | 위에 연결한 해당 제조사의 CPU 지원표 또는 RAM QVL 주소 |
| `verified_at` | 실제 조회 시각 — 이번 자료는 **2026-11-11** |
| `conditions`의 검증 주체 | ASRock / ASUS / MSI / G.SKILL |
| `conditions`의 원문 조건 | CPU 계열, RAM 리비전, DIMM 개수, 검증 속도·전압·프로파일, 검증 BIOS |
| `conditions`의 자료 갱신일 | 페이지에 표시된 경우 보존. 이번 ASRock QVL은 **2026-10-06**, MSI 조회 목록은 **2026-10-12** |

이 구조라면 검증팀은 **CPU 최소 BIOS를 충족하지 않으면 업데이트 전 사용을 막고**, QVL 조건이 일치하면 해당 조건의 검증 근거를 제시할 수 있어. **QVL에 없거나 품번이 불명확한 경우에는 `UNKNOWN`으로 남겨야 하고, 바로 `UNSUPPORTED`로 처리하면 안 돼.**

직접 공부할 때는 **CPU 지원표의 BIOS 열 → RAM QVL의 CPU 세대 선택 → 정확한 품번 검색 → DIMM 개수와 검증 속도 확인** 순서로 보면 돼. 특히 RAM 표의 `1,2`는 슬롯 번호가 아니라 **검증된 메모리 장착 개수**야.
